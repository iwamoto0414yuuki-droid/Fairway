# Fairway 0.4.0：写真の修正事項への対応

## 確認した要望

- 保存済みスコアを修正・削除できるようにする。
- クラブ選択を押しやすいボタンにする。
- 使用クラブを1W・5W・6UT・5I・6I・7I・8I・9I・PW・PTの並びにする。
- クラブを選んだら自動で前の画面へ戻る。
- 写真最下段の項目は、利用者の回答により対象外。
- 説明書を読まなくても分かるUIを重視する。専用デザインエージェントを高性能モデル・低い思考設定で使用し、配置を独立レビューした。

## 画面と動作

- 保存一覧の各ラウンドに「見る・修正・削除」を明示。詳細で合計、続きから入力、ホールごとの修正、ラウンド削除へ進める。
- 削除には対象の日付と全ホールを削除する確認を表示。1タップだけで削除しない。
- 打数と「うちパット」を別の行にし、各−／＋を44ptにする。クラブの入口も幅いっぱい・高さ44pt。
- 「パット＋で打数も＋1」を表示。ホール単位で未入力へ戻す操作にも確認を付ける。
- プレー画面と保存済みホールの修正画面に、共通の1〜18のホール番号を表示する。
- クラブ記録では打目の大きな行を選び、3列のボタングリッドへ進む。各セルは高さ50pt。小さいWatchでは縦スクロールを許容する。
- 指定10本を主な選択肢にし、PTを最後の中央に配置。未記録と罰打は別のボタンにする。
- ローカル保存が成功したら打順の一覧へ1画面戻る。失敗したときは選択画面を閉じない。
- PTを選ぶだけではパット数を変えない。打数・パットとクラブ記録を二重加算しない。

## 保存・同期・互換性

- 既存のv1ライブラリにない削除フィールドはoptionalとして読み込む。schema番号・保存先・bundle IDは変更しない。
- 古いクラブ種別のenumを残し、6UTを追加する。過去のSW等の記録は表示・保持する。
- ラウンド削除は同期用の削除マーカーを残す論理削除。画面から除外し、古い転送データで復活させない。元ファイルからの完全消去を保証する機能ではない。
- 削除マーカーはrevision比較と再起動後の同期にも含める。通常の編集時の競合検査も維持する。
- 0.4.0で6UTや削除を使った後、0.3.0へ戻す運用は対象外。旧版は6UTを知らず、削除マーカーも解釈しない。iPhoneとWatchを同じ新版へ更新する。
- 各タップのローカル保存、ホールを離れたとき等にまとめる同期を継続。タイマー、GPS、地図、運動セッションは追加しない。実際の電池持ちは別途計測が必要。

## 実機で確認すること

1. 元のアプリを削除せず、改修版SideStoreから新版Fairway IPAを上書きする。SideStore本体の更新は不要。
2. 過去のラウンドが残るか、保存一覧から任意のホールを修正できるか確認。
3. 1W〜PTの選択、保存後の自動戻り、6UTの再表示を確認。
4. 不要なテストラウンドを作成して削除し、Watch/iPhoneで反映されるか確認。実際に残したいラウンドで削除検査しない。
5. 両端末の再起動・再接続後にも削除したラウンドが戻らず、別ラウンドのスコアが残るか確認。
6. 新版を手動Refreshし、Watchで起動する。自動Refreshや旧期限後の起動は別の検証として記録する。
