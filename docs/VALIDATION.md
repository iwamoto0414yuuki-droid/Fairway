# Fairway 0.3.0の検証範囲

2026-10-25。旧版のGPSを含む計画は[旧記録](VALIDATION_0.2.0_ARCHIVE.md)へ保存した。現行版はGPS・地図・運動計測を含まない。

## 確認済み

- ネイティブテスト38件成功。打数・パット・任意クラブの記録と既存データの互換性を検査。
- iPhone／Watchの実機向けビルドと未署名IPA作成成功。
- 実IPAの親子ID、プラットフォーム、版番号、Watch同梱、位置情報の利用説明キー削除を検査。
- 40mm Watchシミュレーターで入力・集計・クラブ画面を確認。
- Windows補助EXEはCIおよび今回のWindows PCで自己検査成功。

改修SideStoreと実IPAの追加署名検証は[ビルド結果](WATCH_PERSONAL_RESULTS.md)、導入方法の比較は[再点検](WATCH_RECHECK.md)を参照。

## 実機受け入れで残る項目

1. 既存SideStoreへの更新で認証・アプリ一覧が保持される。
2. 無料アカウントでWatch登録とWatch用profile取得が成功する。
3. FairwayをWatchへ導入でき、Watchから9H・18Hのラウンドを開始できる。
4. 打数を3回・パットを2回追加すると5打2パットになり、ホール移動・アプリ再起動後も保持する。
5. 前半／後半／合計、パット合計がホールの記録と一致する。
6. クラブを選択・変更・未記録へ戻せる。打数を減らしたとき、削除した打のクラブ記録が残らない。
7. Watchで編集したスコアとクラブがiPhoneへ同期する。
8. 通信切断中に別のホールを両端末で編集し、再接続後に両方保持する。同一ホールの競合、古い転送、終了後の転送も確認する。
9. FairwayのRefresh後にWatchでも起動でき、期限更新が反映される。

## 省電力の実測

現在の実機で未計測。まず通常の時計利用と、同時間のFairwayでの入力操作を60分ずつ比較する。次に4〜5時間のラウンドで確認する。開始／終了残量、所要時間、Watchサイズ、バッテリー最大容量、画面設定、気温、通信状態を記録する。端末全体の残量差をアプリ単独の消費量とは扱わない。

常時測位・ポーリング・運動セッションは使わない。操作は端末へ自動保存し、画面離脱などの機会にまとめて転送する。Watchの「時計に戻る」をFairwayだけ1時間後に設定できるが、画面点灯時間の延長とは別の設定。

## 現行版の制約

- 最大打数30、パット数0〜総打数。罰打は総打数へ含める。
- GPS距離、地図、打点、運動記録、常時起動は今回のビルドから除外。
- 編集は自動保存。クラブは任意で、入力を省略できる。
- オフラインで同じホールを両端末から編集した場合は既存の優先規則で片方を採用する。競合履歴の表示はない。
- 既存データの旧項目は読み込み互換性のため残しているが、今回の画面では使わない。
- コンパイル・オフライン署名検証の成功は、Appleの実機profile取得やWatch導入の成功を意味しない。
