# 0.2.0 更新内容

## スコア集計

iPhone/Watchのラウンド画面で、前半（ホール番号1〜9）・後半（10〜18）・全体の打数とパット合計を表示する。9Hラウンドでは全体のみを表示する。途中の合計には入力済みの打数だけを含め、入力済みホール数を表示する。

パット未記録を0として扱わない。0パットは記録済みの0として集計し、未記録は除外する。合計と「記録済みH数」を併記して、途中集計・一部記録を区別する。

## クラブ記録

スコア編集内の「使用クラブ（任意）」から一打ごとに選択する。任意の打を未記録のまま残せる。ドライバー、3/5/7W、3/4/5UT、3〜9I、PW/AW/SW/LW、パター、罰打に対応。

打数は罰打込みなので罰打にも専用の選択肢を用意した。クラブ選択はパット数や打数を自動変更しない。パット数は従来どおり別の任意項目である。

スコア保存時にだけ確定し、戻っただけでは保存しない。打数を減らす場合、対象外になるクラブ記録は保存時に除かれる旨を表示する。取消で未入力に戻した場合はクラブ記録もスコアと一緒に取り消す。コース再利用では前のクラブ記録を複製しない。

## データと省電力

- 既存のBundle ID、Application Supportのrounds-v1.json、Library schema 1を維持。
- Scoreに省略可能なclubsフィールドを追加。0.1.0の既存データはclubs=nilで読み込む。
- スコアとクラブを同じ更新番号で同期し、既存の古い編集拒否・オフラインマージを利用する。
- 新旧バージョン混在で旧版側がクラブを消さないよう、両端末を更新してから利用する案内を追加。
- GPS処理と同期処理のコードは変更なし。集計は保存済みの最大18ホールから計算する。
- クラブ編集は画面内の下書きだけを更新し、保存時の転送にまとめる。位置取得・タイマー・モーション・心拍・常時通信を追加しない。
- 最悪ケース（18H×30打すべてクラブ記録）でも、送信JSONが60KB未満になるテストを追加。

## 検証の追加

前後半集計、未記録と0パット、9H、既存JSON互換、クラブJSON往復・オフラインマージ、入力整合、CSV、最大送信サイズ、再起動保持、旧ファイルへの追記を追加した。自動テスト合計は30件。30件・失敗0件と実機向けビルドに成功。最終パッケージと画面確認の詳細は [RESULTS](RESULTS.md) に記録した。
