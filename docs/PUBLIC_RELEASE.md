# 公開内容と確認した範囲

この公開は、Fairwayの改善と、SideStore経由のApple Watch導入・更新方法の再利用を目的とする。

## 公開するもの

- Fairwayのソース、シミュレーター画面、テスト、ビルド手順。
- 固定された公開上流ソースに適用するWatch対応パッチ。
- 個人情報を含まない失敗・判断・修正の履歴、実機での成功報告の要約。
- 未署名IPAと対応ソースを再ビルドするワークフロー。

## 公開しないもの

利用者の会話原文、端末写真、実際のスコア、アカウント情報、秘密鍵、証明書、実機プロファイル、ペアリングファイル、実UDID。ローカルのbuild/とrelease/をそのまま公開しない。

## 公開前の確認

追跡ソースとGitの全参照から到達するテキスト履歴を、メールアドレス、ユーザーフォルダ、端末ID形式、既知の実チームID、秘密鍵ヘッダー、GitHubトークン形式で検査した。検出した端末ID形式はテスト用ダミー、WindowsパスはGitHub runnerの一般的なビルド位置。コミットメールはnoreplyまたはローカル形式。該当する実個人情報・認証情報は見つからなかった。これはパターン検査であり、あらゆる機微情報の不存在を数学的に保証するものではない。

GitHubの所有者名と、上流ソース由来の著作者表示は公開情報として残す。上流のライセンス・著作者表示は削除しない。過去の履歴は上記検査を行い、今回の公開に不要な新しい利用者情報を追加していない。

## 実機の結果

利用者は今回の目的が完了したと報告した。無料Apple AccountとWindowsでの初期導入後、iPhone上の改修SideStoreでiPhone・WatchへFairwayを導入でき、最終修正版ではRefresh成功とその後のWatch動作も確認した。ショートカット／オートメーション運用の設定も報告されている。自動実行の継続ログや旧署名期限後の起動は追加の確認事項であり、他の利用者・アプリでの成功を保証しない。
